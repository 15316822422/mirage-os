## 说明

- `index.html` 是当前开发版本，`wangyou-os-v3.0.0.html` 是它的发布快照。
- 3.0.0 之后如果继续开发，请保留本文件作为 v3.0.0 的固定副本，再更新 `index.html`。
- 单文件版本包含引擎与全部内置资源，但不包含同目录的 `plugins/`、`skins/` 与文档。
